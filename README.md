# OpenClaw Configuration

个人 OpenClaw 配置文件备份。

## 文件说明

| 文件 | 说明 |
|------|------|
| IDENTITY.md | AI 身份配置（名字、性格等） |
| SOUL.md | AI 行为准则和边界 |
| USER.md | 用户信息和偏好 |
| TOOLS.md | 工具配置和本地笔记 |
| AGENTS.md | Agent 工作流和约定 |
| HEARTBEAT.md | 心跳任务配置 |

## 备份日期
