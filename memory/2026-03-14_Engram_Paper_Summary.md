# 论文总结：Conditional Memory via Scalable Lookup

**论文标题**: Conditional Memory via Scalable Lookup: A New Axis of Sparsity for Large Language Models  
**作者**: Xin Cheng 等 (北京大学 & DeepSeek-AI)  
**日期**: 2025  
**代码**: https://github.com/deepseek-ai/Engram

---

## 📌 核心问题

当前 Transformer 架构缺乏原生的知识查找原语，被迫通过计算来模拟检索，导致：
- 解析常见多 token 实体需要消耗多个早期层
- 浪费宝贵的序列深度在静态模式重建上
- 无法高效区分组合推理和知识检索两种任务

---

## 🔑 核心创新：Engram

**Engram** 是一个条件记忆模块，现代化了经典 N-gram 嵌入，实现 O(1) 查找。

### 架构设计

```
输入 → Tokenizer 压缩 → 多哈希 N-gram → 静态嵌入表 → 上下文感知门控 → 卷积 → 残差连接
```

**关键技术**:
1. **Tokenizer 压缩**: 将语义等价的 token 映射到规范 ID，词表大小减少 23%
2. **多头哈希**: 每个 N-gram 阶数使用 K 个独立哈希头，减少冲突
3. **上下文感知门控**: 使用隐藏状态作为 Query，检索记忆作为 Key/Value，动态调制输出
4. **多分支集成**: 与 mHC 架构集成，共享 Value 投影，独立 Key 投影

---

## 📊 稀疏性分配定律

发现 **U 型缩放定律**：在固定参数预算下，MoE 和 Engram 之间存在最优分配比例

- **最优比例 ρ ≈ 75-80%** (即 20-25% 的稀疏参数分配给 Engram)
- 纯 MoE 基线 (ρ=100%) 并非最优
- 即使 MoE 分配降至 40%，Engram 仍能超越纯 MoE

## 📈 实验结果 (262B tokens 预训练)

| 模型 | 总参数 | 激活参数 | MMLU | CMMLU | BBH | HumanEval | MATH |
|------|--------|----------|------|-------|-----|-----------|------|
| Dense-4B | 4.1B | 3.8B | 48.6 | 47.9 | 42.8 | 26.8 | 15.2 |
| MoE-27B | 26.7B | 3.8B | 57.4 | 57.9 | 50.9 | 37.8 | 28.3 |

- Engram-27B vs MoE-27B (同参数、同 FLOPs):

  - 推理任务：BBH +5.0, ARC-Challenge +3.7, DROP +3.3
  - 代码/数学：HumanEval +3.0, GSM8K +2.2, MATH +2.4

## 🧠 机制分析

### 1. 有效深度增加
- LogitLens 分析：Engram 早期层的预测收敛速度显著快于 MoE
- CKA 相似性分析：Engram 第 5 层 ≈ MoE 第 12 层的表示
- **结论**: Engram 将早期层从静态重建中解放，有效加深网络用于复杂推理

### 2. 注意力容量释放
- 将局部依赖委托给查找，释放注意力用于全局上下文
- 长上下文检索大幅提升：Multi-Query NIAH 84.2 → 97.0

### 3. 系统效率
- 确定性寻址支持运行时从主机内存预取
- 推理时 Engram 表可卸载到主机内存，通信与计算重叠
- 开销可忽略不计

---

## 🏗️ 系统实现

### 训练阶段
- 大规模嵌入表在 GPU 间分片
- 使用 All-to-All 通信原语检索活跃嵌入行

### 推理阶段
- Engram 表卸载到主机内存
- 利用确定性检索逻辑，主机异步预取并传输嵌入
- 与前置 Transformer 块的计算重叠

## 💡 核心结论

1. **条件记忆是 MoE 的理想补充** - 静态查找与动态计算形成互补
2. **稀疏性分配存在最优解** - 约 20-25% 参数分配给记忆模块
3. **收益超越知识检索** - 在推理、代码、数学领域同样显著提升
4. **基础设施感知效率** - 确定性寻址支持高效内存卸载
5. **下一代稀疏模型的必备原语** - 条件记忆应成为标准架构组件
