## 1. 设计目标

从 EngramIndex 获取的种子节点出发，沿 v2.14.0 四正交图边扩散激活，模拟神经科学中的激活扩散机制。

| 指标 | 目标 |
|------|:----:|
| 扩散延迟 | < 3ms |
| 最大深度 | 2 (3 hop 内) |
| 激活节点数 | < 100 (受剪枝) |
| 与衰减集成 | 边权重影响激活值 |

---

## 2. 激活模型

### 2.1 核心公式

```
activation(node, depth) = source_activation × decay_factor^depth × edge_weight

其中:
  source_activation = 种子节点初始值 (Engram lookup score)
  decay_factor     = 扩散衰减因子 (默认 0.5)
  depth            = 距离种子节点的跳数 (0 = 种子自身)
  edge_weight      = 边的当前权重 (考虑衰减后)
```

### 2.2 参数配置

| 参数 | 默认值 | 说明 |
|------|:------:|------|
| `max_depth` | 2 | 最大扩散深度 |
| `decay_factor` | 0.5 | 每跳衰减因子 |
| `threshold` | 0.1 | 激活阈值 (低于此值停止扩散) |
| `max_nodes` | 100 | 最大激活节点数 |
| `semantic_weight` | 0.8 | 语义边扩展权重 |
| `temporal_weight` | 0.6 | 时序边扩展权重 |
| `causal_weight` | 0.5 | 因果边扩展权重 |
| `entity_weight` | 0.3 | 实体边扩展权重 |

### 2.3 激活曲线

```
激活值
1.0 ┤● (种子)
    │ ╲
0.5 ┤  ●──────── (depth=1, semantic edge weight=1.0)
    │   ╲
0.25┤    ●─────── (depth=2, decay 0.25 × edge 1.0)
    │     ╲
0.13┤      ●────  (depth=2, decay 0.25 × edge 0.5)
    │       ╲
0.06┤        ●── (depth=2, temporal edge, below threshold)
    │
0.0 ┼─────────────────────────
    0    1    2    3   depth
```

## 3. 扩散算法

### 3.1 BFS 扩散

```python
from typing import Dict, List, Set, Tuple
from collections import deque


def spreading_bfs(
    seed_scores: Dict[str, float],      # {node_id: initial_score}
    graph,                               # MultiGraphMemory
    max_depth: int = 2,
    decay_factor: float = 0.5,
    threshold: float = 0.1,
    max_nodes: int = 100,
    edge_type_weights: Dict[str, float] = None,
) -> Dict[str, float]:
    """BFS 扩散激活

    Args:
        seed_scores: {node_id: initial_activation}
        graph: MultiGraphMemory 实例
        max_depth: 最大扩散深度
        decay_factor: 每跳衰减因子
        threshold: 激活阈值
        max_nodes: 最大激活节点数
        edge_type_weights: 每种边类型的扩展权重

    Returns:
        {node_id: activation_score}
    """
    if edge_type_weights is None:
        edge_type_weights = {
            'semantic': 0.8,
            'temporal': 0.6,
            'causal': 0.5,
            'entity': 0.3,
        }

    # 累计激活值
    activations: Dict[str, float] = dict(seed_scores)
    # BFS 队列: (node_id, depth, accumulated_score)
    queue: deque = deque()
    visited: Set[Tuple[str, int]] = set()

    for nid, score in seed_scores.items():
        queue.append((nid, 0, score))
        visited.add((nid, 0))

    while queue:
        current_id, depth, current_score = queue.popleft()

        if depth >= max_depth:
            continue

        # 遍历所有四正交子图
        for sg_type in list(graph._graphs.keys()):
            sg = graph._graphs[sg_type]

            # 获取当前节点的出边邻居
            neighbors = sg.get_edges_from(current_id)

            # 边类型权重
            et_weight = edge_type_weights.get(sg_type.value, 0.5)

            for neighbor_id, edge_weight in neighbors:
                # 避免回环
                if (neighbor_id, depth + 1) in visited:
                    continue
                visited.add((neighbor_id, depth + 1))

                # 计算扩散激活
                new_activation = (
                    current_score *
                    (decay_factor ** (depth + 1)) *
                    edge_weight *
                    et_weight
                )

                # 阈值剪枝
                if new_activation < threshold:
                    continue

                # 累积激活 (取最大值)
                if neighbor_id in activations:
                    activations[neighbor_id] = max(
                        activations[neighbor_id], new_activation
                    )
                else:
                    activations[neighbor_id] = new_activation

                # 数量限制
                if len(activations) >= max_nodes:
                    break

                queue.append((neighbor_id, depth + 1, new_activation))

    return activations
```

### 3.2 多路径聚合

同一节点可能从多条路径被激活，聚合策略为**取最大值**：

```python
# 示例: 节点 D 通过两条路径被激活
# Path 1: A → D (via RELATED_TO, weight=0.8)
#   activation_D = 1.0 * 0.5 * 0.8 * 0.8 = 0.32
# Path 2: A → B → D (via NEXT + RELATED_TO)
#   activation_D = 1.0 * 0.25 * 0.6 * 0.8 = 0.12
# Final: activation_D = max(0.32, 0.12) = 0.32
```

### 3.3 伪代码 (完整流程)

```
function spreading_activation(seed_scores, graph, max_depth, decay_factor):
    activations = copy(seed_scores)
    queue = [(nid, 0, score) for nid, score in seed_scores]

    while queue:
        node, depth, score = queue.pop(0)
        if depth >= max_depth: continue

        for subgraph in [TEMPORAL, SEMANTIC, CAUSAL, ENTITY]:
            for neighbor, edge_weight in subgraph.neighbors(node):
                new_score = score * (decay_factor ** (depth+1))
                          * edge_weight * SUBGRAPH_WEIGHT[subgraph]

                if new_score < threshold: continue
                if neighbor in activations:
                    activations[neighbor] = max(activations[neighbor], new_score)
                else:
                    activations[neighbor] = new_score

                queue.append((neighbor, depth+1, new_score))

    return activations
```

## 4. 剪枝策略

### 4.1 三级剪枝

| 剪枝类型 | 条件 | 效果 |
|----------|------|------|
| **阈值剪枝** | activation < 0.1 | 停止该分支扩散 |
| **深度限制** | depth >= 2 | 最多 2 跳 |
| **数量限制** | |activations| >= 100 | 停止所有扩散 |

### 4.2 边类型过滤

```python
# 按查询意图选择扩散边类型
def select_edge_types(intent: str) -> List[str]:
    """根据查询意图选择扩散边类型"""
    intents = {
        'temporal': ['temporal'],          # "昨天做了什么"
        'causal': ['causal'],              # "为什么会这样"
        'semantic': ['semantic'],          # "类似的东西"
        'entity': ['entity'],              # "和XX相关的事"
        'general': ['semantic', 'temporal', 'causal', 'entity'],  # 全部
    }
    return intents.get(intent, intents['general'])
```

### 4.3 衰减边跳过

```python
# 权重过低的边直接跳过
if edge_weight < 0.1:
    continue  # 该边已基本"遗忘"，不参与扩散
```

## 5. SpreadingActivation 类

```python
from typing import Dict, List, Optional
from claw_mem.graph.multi_graph import MultiGraphMemory


class SpreadingActivation:
    """图扩散激活器

    从种子节点出发，沿四正交图边 BFS 扩散，
    模拟神经科学中的激活扩散机制。
    """

    def __init__(self, graph: MultiGraphMemory):
        self._graph = graph
        self._max_depth = 2
        self._decay_factor = 0.5
        self._threshold = 0.1
        self._max_nodes = 100

        # 边类型扩展权重
        self._edge_weights = {
            'semantic': 0.8,
            'temporal': 0.6,
            'causal': 0.5,
            'entity': 0.3,
        }

    def configure(self, max_depth: int = None, decay_factor: float = None,
                  threshold: float = None, max_nodes: int = None) -> None:
        """运行时调整参数"""
        if max_depth is not None:
            self._max_depth = max_depth
        if decay_factor is not None:
            self._decay_factor = decay_factor
        if threshold is not None:
            self._threshold = threshold
        if max_nodes is not None:
            self._max_nodes = max_nodes

    def activate(self, seed_nodes: Dict[str, float],
                 intent: str = 'general') -> Dict[str, float]:
        """执行扩散激活

        Args:
            seed_nodes: {node_id: initial_activation}
            intent: 查询意图，用于选择边类型

        Returns:
            {node_id: activation_score} 包含种子节点
        """
        # 过滤边类型
        filtered_weights = self._filter_weights(intent)

        return spreading_bfs(
            seed_scores=seed_nodes,
            graph=self._graph,
            max_depth=self._max_depth,
            decay_factor=self._decay_factor,
            threshold=self._threshold,
            max_nodes=self._max_nodes,
            edge_type_weights=filtered_weights,
        )

    def _filter_weights(self, intent: str) -> Dict[str, float]:
        """根据意图过滤边类型权重"""
        mapping = {
            'temporal': ['temporal'],
            'causal': ['causal'],
            'semantic': ['semantic'],
            'entity': ['entity'],
            'general': ['semantic', 'temporal', 'causal', 'entity'],
        }
        allowed = mapping.get(intent, mapping['general'])
        return {k: v for k, v in self._edge_weights.items() if k in allowed}

    def get_stats(self) -> dict:
        return {
            'max_depth': self._max_depth,
            'decay_factor': self._decay_factor,
            'threshold': self._threshold,
            'max_nodes': self._max_nodes,
            'edge_weights': self._edge_weights,
        }
```

## 6. 与 MultiGraphMemory 集成

### 6.1 数据流

```
DecoupledRetriever.search(query)
         │
         ▼
    EngramIndex.lookup(query) → seed_nodes: {"mem_1": 0.9, "mem_3": 0.7}
         │
         ▼
    SpreadingActivation.activate(seed_nodes)
         │
         ├──→ MultiGraphMemory.TEMPORAL: mem_1 → mem_2 (NEXT edge)
         ├──→ MultiGraphMemory.SEMANTIC: mem_1 → mem_5 (RELATED_TO edge)
         ├──→ MultiGraphMemory.CAUSAL: mem_3 → mem_8 (DERIVED_FROM edge)
         └──→ MultiGraphMemory.ENTITY: mem_1 → concept_x (HAS_CONCEPT)
         │
         ▼
    activations: {"mem_1": 0.9, "mem_3": 0.7, "mem_2": 0.27, "mem_5": 0.36, ...}
         │
         ▼
    Multi-factor rank → Top-K results
```

### 6.2 只读访问

SpreadingActivation 只读取 MultiGraphMemory 的边结构，不修改图。这保证了并发安全（与衰减操作不同时写）。

## 7. 性能分析

### 7.1 时间复杂度

| 操作 | 复杂度 | 实际 |
|------|:------:|:----:|
| activate() 空种子 | O(1) | < 0.1ms |
| activate() 5 种子 | O(s × d²) | < 1ms |
| activate() 20 种子 | O(s × d²) | < 3ms |
| s = 种子数, d = 平均度数 (~5) |

### 7.2 空间复杂度

| 组件 | 大小 |
|------|:----:|
| activations dict | O(n) ≤ 100 entries |
| visited set | O(n × max_depth) |
| queue | O(n) |
| 总计 | < 10KB |

### 7.3 性能保证

| 指标 | 目标 | 实现 |
|------|:----:|------|
| 激活 5 种子 | < 1ms | BFS 剪枝 |
| 激活 20 种子 | < 3ms | 深度限制 2 |
| 内存开销 | < 10KB | dict 存储 |
