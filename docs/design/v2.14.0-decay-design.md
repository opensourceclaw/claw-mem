## 1. 概述

### 1.1 设计目标

将现有的 `MemoryDecay`（单文件、基于记忆内容的艾宾浩斯衰减）升级为包级模块，支持**边级衰减**，与四正交图集成。

### 1.2 关键设计决策 (已确认)

| 决策 | 选择 | 理由 |
|------|------|------|
| 衰减函数 | **指数衰减** | 论文 Oblivion 推荐 |
| 衰减粒度 | **边级** | 不同边类型不同衰减率 |
| 边权重初始值 | **1.0** | 新关系强，随时间衰减 |
| 图索引更新 | **异步** | 不阻塞存储操作 |

### 1.3 模块结构

```
src/claw_mem/decay/
├── __init__.py              # 导出公共接口
├── functions.py             # 衰减函数实现
├── controller.py            # DecayController - 遗忘控制器
└── scheduler.py             # DecayScheduler - 调度器
```

## 2. 衰减函数

### 2.1 核心公式

采用**指数衰减**模型：

```
weight(t) = base × e^(-λ × days)

其中:
  base     = 初始权重 (1.0)
  λ        = 衰减常数 = ln(2) / half_life_days
  days     = 从边创建到现在经过的天数
  weight   = 衰减后的权重 (0.0 ~ 1.0)
```

### 2.2 衰减函数实现

```python
"""functions.py - 衰减函数"""
import math
from typing import Dict
from enum import Enum


# ── 衰减常数 ─────────────────────────────────────

HALF_LIFE: Dict[str, float] = {
    # 边级半衰期 (天数)
    "episodic": 7.0,        # 情景记忆边: 7 天
    "semantic": 90.0,       # 语义关联边: 90 天
    "procedural": 180.0,    # 程序性记忆边: 180 天
    "temporal": 7.0,        # 时序边: 7 天
    "causal": 14.0,         # 因果边: 14 天
    "entity": 30.0,         # 实体边: 30 天

    # 节点级半衰期 (兼容现有 MemoryDecay)
    "fact_node": 90.0,      # 事实节点
    "episode_node": 7.0,    # 情景节点
}

# 衰减常数 λ = ln(2) / half_life
LAMBDA: Dict[str, float] = {
    k: math.log(2) / v for k, v in HALF_LIFE.items()
}


def exponential_decay(base: float, days: float, half_life: float) -> float:
    """指数衰减

    Args:
        base: 初始权重
        days: 经过天数
        half_life: 半衰期 (天)

    Returns:
        衰减后的权重
    """
    if days <= 0:
        return base
    decay_rate = math.log(2) / half_life  # λ = ln(2) / t½
    return base * math.exp(-decay_rate * days)


def calculate_weight(initial_weight: float, days_elapsed: float,
                     category_half_life: str) -> float:
    """统一的权重计算接口

    Args:
        initial_weight: 初始权重 (通常为 1.0)
        days_elapsed: 经过天数
        category_half_life: 半衰期类别名 ('episodic', 'semantic', ...)

    Returns:
        衰减后权重
    """
    half_life = HALF_LIFE.get(category_half_life, 30.0)
    return exponential_decay(initial_weight, days_elapsed, half_life)


def half_life_to_days(weight: float, initial: float,
                      days_elapsed: float) -> float:
    """根据观察到的衰减逆推半衰期 (用于自适应调整)"""
    if weight >= initial or weight <= 0 or days_elapsed <= 0:
        return 30.0
    # t½ = -ln(2) * days / ln(weight / initial)
    return -math.log(2) * days_elapsed / math.log(weight / initial)
```

```
权重
1.0 ┤●
    │ ╲
0.8 ┤  ╲
    │   ╲__
0.5 ┤      ╲___        ← 半衰期
    │          ╲___
0.3 ┤              ╲___  ← 归档阈值
    │                  ╲
0.1 ┤                    ╲
    │                      ╲
0.0 ┼─────────────────────────────
    0   7d   14d  30d  60d  90d
         (episodic 7天半衰期)
```

### 2.4 权重等级划分

| 权重范围 | 等级 | 操作 |
|----------|:----:|------|
| > 0.7 | Strong | 正常参与检索，高分 |
| 0.3 ~ 0.7 | Medium | 正常参与检索，降权 |
| 0.1 ~ 0.3 | Weak | 可选归档，检索不显示 |
| < 0.1 | Expired | 标记删除，批量清理 |
| < 0.05 | Purged | 物理删除边 |

## 4. 边级衰减实现

### 4.1 DecayController

```python
"""controller.py - 遗忘控制器"""
import time
import threading
from typing import Dict, List, Tuple, Set, Optional
from claw_mem.graph.multi_graph import MultiGraphMemory, SubGraphType
from claw_mem.graph.edges import EdgeType
from claw_mem.decay.functions import (
    calculate_weight, HALF_LIFE, DecayConfig
)


class DecayController:
    """遗忘控制器 - 管理图结构的衰减生命周期

    职责:
      - 计算边权重的衰减
      - 确定哪些边/节点应该归档或删除
      - 与 MultiGraphMemory 集成执行衰减
    """

    def __init__(self, graph: MultiGraphMemory,
                 config: DecayConfig = None):
        self._graph = graph
        self._config = config or DecayConfig.default()
        self._lock = threading.Lock()
        self._last_decay_time: float = 0.0
        self._decay_count: int = 0

    # ── 边级衰减 ────────────────────────────────

    def get_decay_weight(self, edge_tuple: Tuple[str, str],
                         edge_type: str,
                         created_at: float) -> float:
        """计算单条边的衰减后权重

        Args:
            edge_tuple: (source_id, target_id)
            edge_type: 边类型字符串
            created_at: 边创建时间戳

        Returns:
            衰减后的权重 (0.0 ~ 1.0)
        """
        # 1. 获取当前权重 (初始 1.0，之后从图中读取)
        current_weight = 1.0
        for g in self._graph._graphs.values():
            w = g.edge_weights.get(edge_tuple)
            if w is not None:
                current_weight = w
                break

        # 2. 计算经过天数
        days_elapsed = (time.time() - created_at) / 86400.0

        # 3. 获取对应半衰期类别
        category = self._edge_type_to_category(edge_type)

        # 4. 计算新权重
        new_weight = calculate_weight(current_weight, days_elapsed, category)

        # 5. 确保不低于最低阈值
        return max(0.0, min(1.0, new_weight))

    def _edge_type_to_category(self, edge_type: str) -> str:
        """边类型 → 半衰期类别"""
        mapping = {
            "next": "temporal",
            "derived_from": "causal",
            "synthesized_from": "causal",
            "related_to": "semantic",
            "has_concept": "entity",
        }
        return mapping.get(edge_type, "semantic")

    def compute_all_decays(self) -> Dict[Tuple[str, str], float]:
        """计算所有边的衰减权重

        Returns:
            {(source, target): new_weight}
        """
        updates = {}
        now = time.time()

        with self._lock:
            for sg_type, subgraph in self._graph._graphs.items():
                for (s, t), weight in subgraph.edge_weights.items():
                    # 从节点获取创建时间
                    src_node = self._graph.get_node(s)
                    if src_node is None:
                        continue
                    created_at = getattr(
                        src_node, 'created_at',
                        subgraph.edge_weights.get((s, t), now)
                    )
                    days_elapsed = (now - created_at) / 86400.0

                    # 对应半衰期类别
                    category = {
                        SubGraphType.TEMPORAL: "temporal",
                        SubGraphType.CAUSAL: "causal",
                        SubGraphType.SEMANTIC: "semantic",
                        SubGraphType.ENTITY: "entity",
                    }.get(sg_type, "semantic")

                    new_weight = calculate_weight(weight, days_elapsed, category)

                    if new_weight < weight:  # 仅记录衰减的边
                        updates[(s, t)] = new_weight

        return updates

    # ── 清理决策 ────────────────────────────────

    def classify_edges(self) -> Dict[str, List[Tuple[str, str, float]]]:
        """将边按权重等级分类

        Returns:
            {
                "strong": [(source, target, weight), ...],   # > 0.7
                "medium": [...],                              # 0.3 - 0.7
                "weak": [...],                                # 0.1 - 0.3
                "expired": [...],                             # < 0.1
            }
        """
        classified = {"strong": [], "medium": [], "weak": [], "expired": []}

        for sg_type, subgraph in self._graph._graphs.items():
            for (s, t), weight in subgraph.edge_weights.items():
                entry = (s, t, weight)
                if weight > self._config.strong_threshold:
                    classified["strong"].append(entry)
                elif weight > self._config.archive_threshold:
                    classified["medium"].append(entry)
                elif weight > self._config.expire_threshold:
                    classified["weak"].append(entry)
                else:
                    classified["expired"].append(entry)

        return classified

    def should_remove_edge(self, source: str, target: str,
                           weight: float) -> bool:
        """判断边是否应该被移除"""
        if weight <= self._config.purge_threshold:
            return True
        if weight <= self._config.expire_threshold:
            # 检查是否有保护标记
            if self._config.protect_critical:
                src_node = self._graph.get_node(source)
                if src_node and getattr(
                    src_node, 'metadata', {}
                ).get('critical', False):
                    return False
            return True
        return False

    def cleanup_expired(self) -> List[Tuple[str, str]]:
        """清理过期边

        Returns:
            被删除的边列表 [(source, target), ...]
        """
        removed = []
        with self._lock:
            for sg_type in list(SubGraphType):
                for (s, t), weight in list(
                    self._graph._graphs[sg_type].edge_weights.items()
                ):
                    if self.should_remove_edge(s, t, weight):
                        removed.append((s, t))

            if removed:
                # 从图中物理删除
                self._graph.remove_expired_edges(
                    self._config.purge_threshold
                )

        self._decay_count += 1
        self._last_decay_time = time.time()
        return removed

    # ── 状态 ────────────────────────────────

    def get_stats(self) -> dict:
        """获取衰减状态"""
        classified = self.classify_edges()
        total = sum(len(v) for v in classified.values())
        return {
            "total_edges": total,
            "strong_edges": len(classified["strong"]),
            "medium_edges": len(classified["medium"]),
            "weak_edges": len(classified["weak"]),
            "expired_edges": len(classified["expired"]),
            "decay_count": self._decay_count,
            "last_decay_time": self._last_decay_time,
            "config": {
                "half_life_episodic": self._config.half_life_temporal,
                "half_life_semantic": self._config.half_life_semantic,
                "purge_threshold": self._config.purge_threshold,
                "decay_interval_hours": self._config.decay_interval_hours,
            },
        }
```

## 6. 调度器 (DecayScheduler)

### 6.1 调度策略

```python
"""scheduler.py - 衰减调度器"""
import time
import threading
from typing import Optional, Callable


class DecayScheduler:
    """衰减调度器 - 控制衰减任务何时执行

    调度策略:
      - 定时触发: 每 N 小时检查一次
      - 手动触发: 通过 schedule_now() 立即执行
      - 事件触发: 每次 MemoryManager.store() N 次后触发一次

    单线程执行，避免并发修改图结构。
    """

    def __init__(self, controller: "DecayController",
                 config: "DecayConfig" = None):
        from claw_mem.decay.controller import DecayController as DC
        from claw_mem.decay.functions import DecayConfig

        self._controller: DC = controller
        self._config = config or DecayConfig.default()
        self._timer: Optional[threading.Timer] = None
        self._running = False
        self._store_counter = 0          # store() 调用计数
        self._stores_per_decay = 100     # N 次 store 后触发一次衰减
        self._on_complete: Optional[Callable] = None

    def start(self) -> None:
        """启动定期调度"""
        self._running = True
        self._schedule_next()

    def stop(self) -> None:
        """停止调度"""
        self._running = False
        if self._timer:
            self._timer.cancel()
            self._timer = None

    def _schedule_next(self) -> None:
        """安排下一次衰减检查"""
        if not self._running:
            return
        interval = self._config.decay_interval_hours * 3600
        self._timer = threading.Timer(interval, self._run_decay_cycle)
        self._timer.daemon = True
        self._timer.start()

    def _run_decay_cycle(self) -> None:
        """执行一次衰减周期"""
        try:
            # 1. 计算所有衰减
            updates = self._controller.compute_all_decays()
            if updates:
                self._controller._graph.apply_decay(updates)

            # 2. 清理过期边
            removed = self._controller.cleanup_expired()
            if removed and self._on_complete:
                self._on_complete(removed)

        except Exception as e:
            # 衰减失败不影响主流程
            import logging
            logging.getLogger("claw_mem").warning(
                f"Decay cycle failed: {e}"
            )
        finally:
            if self._running:
                self._schedule_next()

    def schedule_now(self) -> None:
        """手动触发立即衰减"""
        threading.Thread(
            target=self._run_decay_cycle, daemon=True
        ).start()

    def notify_store(self) -> None:
        """通知一次 store() 调用发生"""
        self._store_counter += 1
        if self._store_counter >= self._stores_per_decay:
            self._store_counter = 0
            self.schedule_now()

    def on_complete(self, callback: Callable) -> None:
        """注册衰减完成回调"""
        self._on_complete = callback
```

### 6.2 调度时间线

```
时刻 0: DecayScheduler.start()
时刻 24h: 定时触发 → run_decay_cycle()
时刻 48h: 定时触发 → run_decay_cycle()
时刻 72h: 定时触发 → run_decay_cycle()
...
期间: 每 100 次 store() → notify_store() → schedule_now()
```

## 7. 清理策略

### 7.1 三级清理

```
Level 1 - 权重衰减 (Continuous)
  └── 每次衰减周期: 更新所有边权重
      (不删除，仅降低权重)

Level 2 - 归档 (Periodic, 每天一次)
  └── 权重 < 0.3: 标记为 weak
      检索时这些边被忽略，但数据保留

Level 3 - 物理删除 (Periodic, 每 7 天一次)
  └── 权重 < 0.05: 物理删除边
      同时检查: 孤立节点也可删除
```

### 7.2 孤立节点清理

```python
def cleanup_orphan_nodes(graph: MultiGraphMemory) -> List[str]:
    """清理没有边的孤立节点"""
    connected = set()
    for sg_type in SubGraphType:
        subgraph = graph._graphs[sg_type]
        for (s, t) in subgraph.edge_weights.keys():
            connected.add(s)
            connected.add(t)

    orphans = []
    for nid in list(graph._node_index.keys()):
        if nid not in connected:
            # 检查是否是关键/受保护的节点
            node = graph.get_node(nid)
            if node and getattr(
                node, 'metadata', {}
            ).get('protected', False):
                continue
            orphans.append(nid)
            del graph._node_index[nid]
            for g in graph._graphs.values():
                g.nodes.discard(nid)

    return orphans
```

### 7.3 保护机制

| 保护类型 | 条件 | 效果 |
|----------|------|------|
| 关键规则 | metadata.critical = True | 永不过期 |
| 置顶记忆 | metadata.pinned = True | 不衰减 |
| 最近创建 | created_at < 24h | 跳过首轮衰减 |
| 高频访问 | access_count > 10 | 半衰期 × 2 |

## 9. 性能分析

### 9.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|:------:|------|
| calculate_weight | O(1) | 纯数学计算 |
| get_decay_weight | O(1) | 常数查找 |
| compute_all_decays | O(E) | 遍历所有边 |
| classify_edges | O(E) | 遍历所有边 |
| cleanup_expired | O(E) | 遍历 + 删除 |
| schedule_now | O(E) | 异步，不阻塞主线程 |

| 组件 | 开销 |
|------|------|
| DecayConfig | ~200 bytes (常量) |
| DecayController | ~1KB (状态 + 引用) |

### 9.3 性能保证

| 指标 | 目标 | 实现 |
|------|:----:|------|
