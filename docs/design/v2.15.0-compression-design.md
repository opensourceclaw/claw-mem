## 1. 设计目标

将原始记忆逐级压缩为更高抽象层次的知识，减少 Token 浪费，提升上下文利用率。

| 级别 | 输出 | Token 减少 | 抽象度 |
|:----:|------|:----------:|:------:|
| L0 | 原始 Episodes | 0% | 原始 |
| L1 | Skills | 50% | 流程 |
| L2 | Rules | 75% | 规则 |
| L3 | Principles | 90% | 原则 |

---

## 2. 四级压缩模型

### 2.1 Level 0: Episodes (原始记忆)

原始对话记录，完整保留，不做任何修改。

```python
@dataclass
class EpisodeEntry:
    content: str          # 完整对话内容
    memory_id: str        # 对应记忆 ID
    timestamp: float
    access_count: int = 0  # 访问计数
```

### 2.2 Level 1: Skills (技能)

从反复出现的 Episodes 中提取可复用的流程。

```
输入 (多个 Episodes):
  "用户问如何配置 Redis 缓存 → 安装 redis-py → 配置连接池 → 使用装饰器缓存结果"
  "用户问 Redis 缓存问题 → pip install redis → 配置 max_connections=10"
  ...

输出 (Skill):
  Title: "配置 Redis 缓存"
  Steps:
    1. pip install redis
    2. 创建 redis.ConnectionPool(max_connections=10)
    3. 使用 redis.Redis(connection_pool=pool)
    4. @cache_result 装饰器缓存函数结果
  Tags: redis, cache, database, python
```

```python
@dataclass
class SkillEntry:
    skill_id: str
    title: str                # 技能标题
    description: str          # 简短描述
    steps: List[str]          # 操作步骤
    source_episodes: List[str] # 来源 Episode IDs
    tags: List[str]           # 标签
    apply_count: int = 0      # 应用次数
    created_at: float = 0.0
    updated_at: float = 0.0
```

### 2.3 Level 2: Rules (规则)

从 Skills 中提取条件-动作规则。

```
输入 (多个 Skills):
  Skill: "配置 Redis 缓存" (Steps: pip install redis, ...)
  Skill: "配置 Memcached" (Steps: pip install python-memcached, ...)
  ...

输出 (Rule):
  Condition: "用户需要缓存功能"
  Action: "建议使用 Redis，若内存极小 (< 256MB) 则用 Memcached"
  Confidence: 0.85
  Source Skills: ["配置 Redis 缓存", "配置 Memcached"]
```

```python
@dataclass
class RuleEntry:
    rule_id: str
    condition: str            # 触发条件
    action: str               # 执行动作
    confidence: float         # 置信度 (0.0 ~ 1.0)
    source_skills: List[str]  # 来源 Skill IDs
    validation_count: int = 0 # 验证次数
    created_at: float = 0.0
```

### 2.4 Level 3: Principles (原则)

从 Rules 中提取最高层的抽象原则。

```
输入 (多个 Rules):
  Rule: "用户需要缓存功能 → 建议 Redis"
  Rule: "用户需要搜索功能 → 建议 Elasticsearch"
  Rule: "日志需求 → 建议结构化日志 + ELK"
  ...

输出 (Principle):
  "优先选择生态成熟、社区活跃的开源组件，而非自研方案"
  Confidence: 0.9
  Source Rules: [...]
```

```python
@dataclass
class PrincipleEntry:
    principle_id: str
    content: str                  # 原则内容 (一句话)
    confidence: float             # 置信度
    source_rules: List[str]       # 来源 Rule IDs
    created_at: float = 0.0
```

### 2.5 压缩流程示意

```
┌──────────────────────────────────────────────┐
│                Compression Spectrum           │
├──────────────────────────────────────────────┤
│                                               │
│  L0: ["对话1", "对话2", "对话3", ...]        │
│       │ access_count > 5                      │
│       ▼                                       │
│  L1: Skill: "配置 Redis 缓存"                │
│       │ same_tag_skills > 3                   │
│       ▼                                       │
│  L2: Rule: "缓存 → Redis"                    │
│       │ same_confidence_rules > 2             │
│       ▼                                       │
│  L3: Principle: "优先成熟开源组件"            │
│                                               │
└──────────────────────────────────────────────┘
```

## 3. CompressionSpectrum 类

```python
import time
import uuid
from typing import List, Dict, Optional
from dataclasses import dataclass


@dataclass
class CompressedMemory:
    """压缩后的记忆实体"""
    memory_id: str
    level: int                 # 0-3
    content: str               # 压缩后的内容
    source_ids: List[str]      # 来源记忆 ID 列表
    created_at: float
    metadata: Dict = None

    def __post_init__(self):
        if self.metadata is None:
            self.metadata = {}


class CompressionSpectrum:
    """三级压缩谱 (L1→L2→L3)

    设计原则:
      - 默认关闭 (enable_compression=False)
      - 触发式压缩 (基于访问/应用/验证次数)
      - 规则提取 (不依赖 LLM，基于模板)
      - 与现有 MemoryCompressorV2 互补
    """

    def __init__(self, memory_manager=None):
        self._mm = memory_manager
        self._skills: Dict[str, SkillEntry] = {}
        self._rules: Dict[str, RuleEntry] = {}
        self._principles: Dict[str, PrincipleEntry] = {}

        # 触发阈值
        self._skill_access_threshold = 5   # Episode 访问 > N 次
        self._rule_apply_threshold = 3     # Skill 应用 > N 次
        self._principle_verify_threshold = 2  # Rule 验证 > N 次

        # 访问计数 (Episode ID → count)
        self._episode_access: Dict[str, int] = {}

    # ── 压缩触发 ─────────────────────────────

    def record_access(self, memory_id: str) -> Optional[CompressedMemory]:
        """记录一次记忆访问，检查是否触发压缩

        Returns:
            压缩结果 (如果有新压缩)，否则 None
        """
        self._episode_access[memory_id] = (
            self._episode_access.get(memory_id, 0) + 1
        )

        count = self._episode_access[memory_id]
        if count >= self._skill_access_threshold:
            return self._compress_to_skill(memory_id)

        return None

    def record_apply(self, skill_id: str) -> Optional[CompressedMemory]:
        """记录一次技能应用，检查是否压缩为规则"""
        skill = self._skills.get(skill_id)
        if skill is None:
            return None

        skill.apply_count += 1
        if skill.apply_count >= self._rule_apply_threshold:
            return self._compress_to_rule(skill_id)

        return None

    def record_verify(self, rule_id: str) -> Optional[CompressedMemory]:
        """记录一次规则验证，检查是否压缩为原则"""
        rule = self._rules.get(rule_id)
        if rule is None:
            return None

        rule.validation_count += 1
        if rule.validation_count >= self._principle_verify_threshold:
            return self._compress_to_principle(rule_id)

        return None

    # ── 压缩算法 ─────────────────────────────

    def _compress_to_skill(self, episode_id: str) -> Optional[CompressedMemory]:
        """从单个 Episode 提取 Skill (规则引擎)

        策略:
          1. 识别操作动词 ("install", "配置", "创建", "使用", etc.)
          2. 提取步骤序列
          3. 生成描述和标签
        """
        # 获取 Episode 内容
        episode_content = self._get_episode_content(episode_id)
        if not episode_content:
            return None

        # 规则提取:
        steps = self._extract_steps(episode_content)
        if len(steps) < 2:
            return None

        title = self._generate_skill_title(episode_content)
        tags = self._extract_tags(episode_content)

        skill_id = f"skill_{uuid.uuid4().hex[:12]}"
        skill = SkillEntry(
            skill_id=skill_id,
            title=title,
            description=episode_content[:200],
            steps=steps,
            source_episodes=[episode_id],
            tags=tags,
            apply_count=0,
            created_at=time.time(),
            updated_at=time.time(),
        )
        self._skills[skill_id] = skill

        # 构建压缩记忆
        content = f"[Skill] {title}\n" + "\n".join(
            f"  {i+1}. {s}" for i, s in enumerate(steps)
        )

        return CompressedMemory(
            memory_id=skill_id,
            level=1,
            content=content,
            source_ids=[episode_id],
            created_at=time.time(),
            metadata={"type": "skill", "tags": tags},
        )

    def _compress_to_rule(self, skill_id: str) -> Optional[CompressedMemory]:
        """从 Skill 提取 Rule

        策略:
          1. 识别技能目标和条件
          2. 生成条件→动作规则
        """
        skill = self._skills.get(skill_id)
        if skill is None:
            return None

        # 从 Skill title 和 steps 推断 condition + action
        condition = f"用户需要 {skill.title}"
        action = f"按以下步骤操作: {' → '.join(skill.steps[:3])}"

        rule_id = f"rule_{uuid.uuid4().hex[:12]}"
        rule = RuleEntry(
            rule_id=rule_id,
            condition=condition,
            action=action,
            confidence=0.7,
            source_skills=[skill_id],
            validation_count=0,
            created_at=time.time(),
        )
        self._rules[rule_id] = rule

        return CompressedMemory(
            memory_id=rule_id,
            level=2,
            content=f"[Rule] IF {condition} THEN {action}",
            source_ids=[skill_id],
            created_at=time.time(),
            metadata={"type": "rule", "confidence": 0.7},
        )

    def _compress_to_principle(self, rule_id: str) -> Optional[CompressedMemory]:
        """从 Rule 提取 Principle

        策略:
          1. 聚合多个 Rules 的模式
          2. 提取通用原则
        """
        rule = self._rules.get(rule_id)
        if rule is None:
            return None

        # 简化原则生成: 从 action 中提取核心建议
        principle_content = f"优先 {rule.action[:100]}"

        principle_id = f"prin_{uuid.uuid4().hex[:12]}"
        principle = PrincipleEntry(
            principle_id=principle_id,
            content=principle_content,
            confidence=rule.confidence,
            source_rules=[rule_id],
            created_at=time.time(),
        )
        self._principles[principle_id] = principle

        return CompressedMemory(
            memory_id=principle_id,
            level=3,
            content=f"[Principle] {principle_content}",
            source_ids=[rule_id],
            created_at=time.time(),
            metadata={"type": "principle", "confidence": rule.confidence},
        )

    # ── 查询 ─────────────────────────────────

    def get_compressed(self, memory_id: str = None,
                       level: int = None) -> List[CompressedMemory]:
        """获取压缩后的记忆"""
        results = []
        # 查询依赖链
        if memory_id:
            for skill in self._skills.values():
                if memory_id in skill.source_episodes:
                    results.append(self._skill_to_compressed(skill))
        return results

    # ── 辅助方法 ─────────────────────────────

    def _get_episode_content(self, memory_id: str) -> Optional[str]:
        """从 MemoryManager 获取原始内容"""
        if self._mm is None:
            return None
        # 使用 search 获取记忆内容
        try:
            results = self._mm.get(memory_id)
            return results.get("content") if results else None
        except Exception:
            return None

    def _extract_steps(self, content: str) -> List[str]:
        """从内容中提取操作步骤"""
        import re
        steps = []
        # 匹配操作动词引导的句子
        action_patterns = [
            r'(install|pip install|npm install|brew install)\s+\S+',
            r'(配置|设置|修改|创建|使用|运行|启动|停止|删除)\s+\S+',
            r'(create|configure|set up|run|start|stop|delete)\s+\S+',
        ]
        for pattern in action_patterns:
            matches = re.findall(pattern, content, re.IGNORECASE)
            steps.extend(matches)
        # 去重
        seen = set()
        unique = []
        for s in steps:
            if s.lower() not in seen:
                seen.add(s.lower())
                unique.append(s)
        return unique[:10]

    def _generate_skill_title(self, content: str) -> str:
        """生成技能标题"""
        # 取第一句或前 50 个字符
        first_line = content.split('\n')[0].strip()
        return first_line[:80]

    def _extract_tags(self, content: str) -> List[str]:
        """提取标签"""
        import re
        # 提技术名词
        tech_keywords = [
            'python', 'javascript', 'typescript', 'go', 'rust',
            'redis', 'postgresql', 'mysql', 'mongodb',
            'docker', 'kubernetes', 'aws', 'api', 'rest',
            '缓存', '数据库', '容器', '部署', '监控',
        ]
        found = []
        for kw in tech_keywords:
            if kw.lower() in content.lower():
                found.append(kw)
        return found[:5]

    def _skill_to_compressed(self, skill: SkillEntry) -> CompressedMemory:
        return CompressedMemory(
            memory_id=skill.skill_id,
            level=1,
            content=f"[Skill] {skill.title}",
            source_ids=skill.source_episodes,
            created_at=skill.created_at,
            metadata={"type": "skill"},
        )

    # ── 统计 ─────────────────────────────────

    def get_stats(self) -> dict:
        return {
            "skills": len(self._skills),
            "rules": len(self._rules),
            "principles": len(self._principles),
            "total_episodes_tracked": len(self._episode_access),
            "thresholds": {
                "skill_access": self._skill_access_threshold,
                "rule_apply": self._rule_apply_threshold,
                "principle_verify": self._principle_verify_threshold,
            },
        }
```

## 4. 压缩触发机制

### 4.1 触发条件

| 触发 | 条件 | 动作 |
|------|------|------|
| Episode → Skill | 同一 Episode 被访问 > 5 次 | `_compress_to_skill()` |
| Skill → Rule | 同一 Skill 被应用 > 3 次 | `_compress_to_rule()` |
| Rule → Principle | 同一 Rule 被验证 > 2 次 | `_compress_to_principle()` |

### 4.2 访问追踪集成

```python
# 在 MemoryManager.search() 中集成
def search(self, query, ...):
    results = self._do_search(query)

    # 记录搜索命中的记忆 (用于触发压缩)
    if self._compression_spectrum:
        for r in results:
            self._compression_spectrum.record_access(r.get("id", ""))

    return results
```

## 5. 与现有压缩器的关系

| 压缩器 | 职责 | v2.15.0 变化 |
|--------|------|--------------|
| `MemoryCompressorV2` | 锯齿模式去重 + KnowledgeBlock | 保留不变 |
| `F5CompressorV2` | 句子级压缩 | 保留不变 |
| `CompressionSpectrum` | 四级抽象压缩 | **新增** |

三者互补：
- **MemoryCompressorV2**: 会话级去重和关键信息持久化
- **F5CompressorV2**: 内容级句子压缩
- **CompressionSpectrum**: Episode → Skill → Rule → Principle 纵向抽象

`enable_compression` 控制 CompressionSpectrum，默认关闭，需要验证。

## 6. 性能分析

### 6.1 时间复杂度

| 操作 | 复杂度 | 实际 |
|------|:------:|:----:|
| record_access() | O(1) | 计数器 + 规则匹配 |
| _compress_to_skill() | O(n) | n = 内容长度 |
| _extract_steps() | O(n) | 正则匹配 |
| get_compressed() | O(s) | s = skills 数量 |

### 6.2 空间复杂度

| 场景 | Skills | Rules | Principles | 总计 |
|------|:------:|:-----:|:----------:|:----:|
| 100 Episodes | ~5 | ~2 | ~1 | < 10KB |
| 1000 Episodes | ~50 | ~15 | ~5 | < 50KB |

### 6.3 不阻塞主线

所有压缩操作在 `record_access()` 路径上同步执行（O(n) 规则匹配），但可通过异步化减轻负担。MVP 阶段先同步，后续视性能数据决定是否移至后台线程。
