# claw-mem v7.11.0 — Card Prediction Triplet and Manifest Alignment

> **Scope**: minor release. Adds the card-effectiveness prediction/backfill triplet, aligns the plugin manifest with the real 21-tool surface, moves performance benchmarks onto an explicit path, and upgrades the claw-ctx dependency. Schema changes are additive; no migration is required.

## Highlights

- Card effectiveness now records pre-adoption attempts, backfills fixed and missed outcomes, and reports fixed rates without fabricating numbers: `fixedRate` is `null` when the denominator is zero.
- The plugin manifest and the registered tool surface are reconciled: `declared ∪ explicit exemptions = registered`, locked by tests in both directions.
- Performance benchmarks no longer run in the default test path; `npm run bench` is the explicit entry point.

## Changes

### Card prediction/backfill triplet (`ae00cc70`)

`CardEffectiveness.attempts[]` records each attempt before adoption via `recordCardAttempt` (duplicate `runId` rejected). Outcomes are backfilled through `fixedIds` / `missedIds` / `backfilled`, and `getCardAttemptStats` counts only `backfilled=true` entries; a zero denominator yields `fixedRate = null`. Host writeback is system-only and never caller-set.

### Manifest contract alignment (`18285de9`, `9c6520cc`)

`contracts.tools` grows from 16 to 21, declaring `error_pattern_card_store` plus the navigation tools. The reconciliation test now asserts `declared ∪ explicit exemptions = registered`; the exemption list is empty and guarded against silent additions. Data-carrying empty objects declare `additionalProperties: true`, while `get_constitution` top-level parameters are closed.

### Benchmark split (`b04641af`)

The 8 benchmark tests live in `vitest.bench.config.ts` and run through `npm run bench`; the default `npm test` path is deterministic. CI performance coverage requires an explicit bench run.

### Dependencies (`d7fb35dd`, `09fd1738`)

- claw-ctx 6.6.1 → 6.16.0: cost/cache annotation ledger and `claw-ctx cost` CLI, persisted usage fallback, idempotent `commitTurn`, release CJK preflight. The new version declares peer dependencies on `openclaw` and `@earendil-works/pi-agent-core`, both satisfied by existing dev dependencies.
- `@hono/node-server` override 2.1.3 → 2.1.11 (GHSA-qv5m-9pm6-hqp3, GHSA-jpvv-r467-5p4w).

## Tests

- Full suite: **93** files / **1086** passed / **0** failed (default path).
- Real-config sweep (`687dab92`): plugin-config tests read the real `openclaw.plugin.json`; V-ref tests walk real rejection JSONL records (5 rule IDs).
- `tsc --noEmit`: 0 errors.

## Upgrade Notes

- No configuration or schema migration is required; new fields are additive.
- If any repository installed claw-ctx **6.16.0** as a dependency, verify its local hook path with `git config --local core.hooksPath`. If it was changed to `.githooks`, restore the previous value (for example `git config core.hooksPath scripts/git-hooks`). claw-ctx 6.16.1 fixes the packaging defect that rewrote consumer hook paths.
- Run `npm run bench` for performance coverage; `npm test` no longer includes the benchmark suite.
